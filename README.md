# RADDIA

Système de charge intelligent — 50 casiers sécurisés pour recharger son téléphone, pilotés en temps réel.

Ce dépôt contient l'app **Gestionnaire** : l'outil pour superviser et piloter une borne à distance (mobile, tablette, ordinateur).

## Fonctionnalités

- Vue en direct des 50 casiers (libre / en charge / prêt / erreur)
- Déverrouillage à distance
- Alertes automatiques
- Statistiques d'usage
- Multi-bornes
- Authentification

## Démarrer

```bash
npm install
npm run dev
```
